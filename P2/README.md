# Pertemuan 2

Membuat Hello World pada Flutter

## Ringkasan

Pertemuan ini melanjutkan lingkungan yang sudah disiapkan pada P1, dengan
fokus pada **membuat aplikasi Flutter pertama** dan menjalankannya di
emulator Android.

Materi pertemuan ini berasal dari video pembelajaran dosen serta modul
praktikum mata kuliah Pemrograman Berbasis Perangkat Bergerak.

## Lingkungan yang Dibutuhkan

Perangkat lunak yang harus sudah terpasang sebelum memulai (dijelaskan
pada P1):

- Android Studio
- Git
- Flutter SDK
- Visual Studio Code

Detail versi, lokasi pemasangan, dan perintah pengaturannya tercatat di
[README utama](../README.md).

## Langkah Praktikum

Urutan kerja mengikuti modul praktikum:

1. Membuat project Flutter baru
2. Menyiapkan emulator Android (AVD Manager)
4. Menjalankan project di emulator
5. Menulis kode Hello World pada `lib/main.dart`
6. Menjalankan ulang dan melihat hasilnya

Seluruh langkah di atas sudah terbukti dikerjakan pada pertemuan ini dan
dilanjutkan pada P1 — termasuk pembuatan project dengan `flutter create`,
pembuatan AVD, build APK debug, dan menjalankan aplikasi sungguhan di
emulator. Bukti pengujiannya ada di
[README P1](../P1/README.md).

## Catatan Materi

Materi pertemuan ini berisi video pembelajaran yang sama dengan pertemuan 3
pada folder dokumen (nama berkas identik), sehingga pembahasan keduanya
tumpang tindih: keduanya membahas pembuatan project dan Hello World.

Modul praktikum versi dosen menggunakan langkah lewat Android Studio dan
Visual Studio Code pada Windows dengan JDK 15. Praktikum di repositori ini
dikerjakan di Linux dengan Flutter 3.35.1 dan OpenJDK 21, sehingga
penyesuaian yang diperlukan — izin KVM untuk emulator dan penunjukan JDK
untuk Gradle — tercatat di [README utama](../README.md).
