## Soal Ujian

Soal terdiri dari tiga pertanyaan uraian.

### Soal 1

Apa perbedaan utama antara `StatelessWidget` dan `StatefulWidget` di
Flutter? Berikan contoh kapan Anda harus menggunakan masing-masing tipe
widget tersebut!

### Soal 2

Dalam Flutter, terdapat tiga jenis tree utama saat aplikasi berjalan
(runtime), yaitu Widget Tree, Element Tree, dan RenderObject Tree.
Jelaskan fungsi singkat dari ketiga tree tersebut dan bagaimana
keterhubungannya!

### Soal 3

Widget apa yang biasa digunakan di Flutter untuk menampilkan data yang
diambil dari API secara asynchronous (menggunakan `Future`), dan sebutkan
3 kondisi/status (state) utama yang umumnya harus ditangani di dalam
widget tersebut!
